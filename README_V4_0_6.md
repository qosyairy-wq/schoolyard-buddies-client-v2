# Schoolyard Buddies v4.0.6 — Gameplay-Only Mobile Controls

- Joystick and chat icon are hidden on loading, title, profile and main-menu screens.
- Controls appear only after the player enters the actual 3D world.
- The right half of the screen is restored as an invisible POV/camera swipe zone.
- POV control is hidden while menus, dialogs, shops or Chat Room are open.
- Input is reset whenever gameplay is left, preventing stuck movement.
