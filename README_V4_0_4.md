# Schoolyard Buddies v4.0.4 — Mobile Control Rebuild

- Disables all legacy joystick layers.
- Creates one independent, always-visible joystick in the bottom-left.
- Hides the legacy chat panel during gameplay.
- Shows one chat icon below the Menu button.
- Mirrors unread notifications onto the new chat icon.
- Opens Chat Room as a full-screen mobile page.
- Includes a permanent X button and Enter-to-send support.
